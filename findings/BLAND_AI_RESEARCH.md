## Script Formatting for Bland AI

### Basic Script Structure

Bland AI uses a prompt-based system for scripting AI conversations. While Bland AI doesn't explicitly document a specific markup language for voice modulation, scripts should follow these structural elements:

1. **Agent identity**: Define who the AI agent is, their role, and their speaking style
2. **Conversation objective**: Clearly state the purpose of the call
3. **Sample dialogues**: Provide examples of how conversations should flow
4. **Response guidelines**: Instructions on how to handle specific situations

Example basic script structure:

```
Your name is [Name], and you're a [Role] at [Company]. Your goal is to [Objective].

Here's an example dialogue:
Person: [Example customer statement]
You: [Example response with appropriate tone]

When speaking, you should be [personality traits] and focus on [key points].
```

### Formatting for Voice Modulation

While Bland AI doesn't have publicly documented specific markup for voice modulation, the platform likely interprets certain text formatting cues similar to other AI voice systems. Based on industry standards and best practices, the following formatting approaches can be used:

1. **Punctuation**: Use standard punctuation to indicate natural pauses and sentence structure
2. **Capitalization**: Use ALL CAPS sparingly to indicate emphasis on specific words
3. **Text structure**: Break text into shorter sentences and paragraphs for better pacing
4. **Conversational style**: Write in a natural, conversational tone rather than formal written language

## Voice Modulation Techniques

### Indicating Tone and Emotion

To indicate tone and emotion in Bland AI scripts, consider these approaches:

1. **Explicit instructions**: Include tone directions in the prompt (e.g., "Speak in a friendly, enthusiastic tone")
2. **Contextual cues**: Provide context that naturally evokes the desired tone
3. **Punctuation**: Use exclamation points for enthusiasm, question marks for curiosity
4. **Word choice**: Select words that naturally convey the intended emotion

### Controlling Pace and Pauses

To control pacing and pauses in AI voice delivery:

1. **Sentence length**: Shorter sentences create a faster pace, longer sentences slow it down
2. **Punctuation**: Use commas for short pauses, periods for longer pauses
3. **Paragraph breaks**: Create natural pauses between topics or sections
4. **Ellipses**: Use "..." to indicate a thoughtful pause or trailing off

### Emphasis and Inflection

To indicate emphasis and inflection in Bland AI scripts:

1. **Word order**: Place important information at the beginning or end of sentences
2. **Italics or bold**: While not explicitly supported, using *italics* or **bold** in the prompt may help convey emphasis intention
3. **Sentence structure**: Use questions to naturally create rising inflection
4. **Contextual cues**: Provide context that suggests the appropriate emphasis

## Best Practices for AI Voice Scripts

### Writing for Clarity and Comprehension

1. **Simple language**: Use straightforward vocabulary and avoid complex jargon
2. **Short sentences**: Keep sentences concise and focused on one idea
3. **Active voice**: Use active rather than passive voice for clarity
4. **Phonetic spelling**: For difficult words, consider including phonetic pronunciation

### Creating Natural-Sounding Dialogue

1. **Conversational language**: Write how people actually speak, not how they write
2. **Contractions**: Use contractions (e.g., "don't" instead of "do not") for natural speech
3. **Filler words**: Include occasional filler words ("um," "well," "you know") sparingly
4. **Varied sentence structure**: Mix short and medium-length sentences for rhythm

### Testing and Iteration

1. **Listen to output**: Test scripts with the AI voice and adjust as needed
2. **A/B testing**: Create multiple versions to determine which performs best
3. **Gather feedback**: Collect responses from call recipients to improve scripts
4. **Continuous improvement**: Regularly update scripts based on performance data

## Human vs. AI Voice Scripting Differences

### Key Differences

1. **Interpretation ability**: Human callers can interpret vague instructions; AI needs explicit guidance
2. **Contextual understanding**: Humans naturally understand context; AI may need it spelled out
3. **Improvisation**: Humans can improvise; AI needs more structured conversation paths
4. **Emotional intelligence**: Humans naturally detect and respond to emotions; AI needs programmatic cues

### Adapting Human Scripts for AI

1. **Add context**: Provide more background information for the AI
2. **Structure options**: Create clear pathways for different conversation directions
3. **Simplify language**: Remove idioms, complex metaphors, and ambiguous phrasing
4. **Add pronunciation guides**: For unusual names or terms, include pronunciation guidance

## Script Formatting Cheat Sheet

### Quick Reference Guide for Voice Modulation

| Element                 | Technique                            | Example                                                            |
| ----------------------- | ------------------------------------ | ------------------------------------------------------------------ |
| **Emphasis**            | Use ALL CAPS for key words           | "This offer is ONLY available today"                               |
| **Pauses**              | Use punctuation strategically        | "Hello, [pause] is this a good time to talk?"                      |
| **Tone - Friendly**     | Use exclamations, warm language      | "Great to connect with you today!"                                 |
| **Tone - Professional** | Use formal language, measured pace   | "I appreciate your consideration of our proposal."                 |
| **Pace - Faster**       | Short sentences, minimal punctuation | "Quick update. New features ready. Launch next week."              |
| **Pace - Slower**       | Longer sentences, more punctuation   | "I'd like to take a moment to explain, in detail, how this works." |
| **Low Pitch (130Hz)**   | Indicate serious, authoritative tone | "[serious tone] This matter requires immediate attention."         |
| **High Pitch (180Hz)**  | Indicate excitement, questions       | "[excited] We've just launched an amazing new feature!"            |
| **Rising Inflection**   | Use question format                  | "Wouldn't that be valuable for your team?"                         |
| **Falling Inflection**  | Use declarative statements           | "This solution will save you time and money."                      |
